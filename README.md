# my history learn java script

🟢 Fase 1: Fondasi & Logika Dasar (Hari 1-20)
Fokus di sini adalah membiasakan jemari kamu dengan sintaks JS di WebStorm.

Hari 1-5: Mengenal Variabel (let, const), Tipe Data (String, Number, Boolean, Null, Undefined), dan Console.

Hari 6-10: Operator Aritmatika & Logika. Memahami perbandingan (== vs ===).

Hari 11-15: Struktur Kendali (if-else, switch case) dan perulangan (for, while).

Hari 16-20: Fungsi (Function). Pahami cara membuat fungsi, parameter, dan return value.


🔵 Fase 2: DOM & Interaktivitas Web (Hari 21-40)
Di sini kamu mulai menghubungkan JS dengan HTML/CSS.

Hari 21-25: Mengenal DOM (Document Object Model). Cara memilih elemen (querySelector, getElementById).

Hari 26-30: Event Listeners. Menangani click, submit, input, dan hover.

Hari 31-35: Manipulasi Elemen. Mengubah teks, warna, hingga menambah/menghapus Class CSS secara dinamis.

Hari 36-40: Proyek Kecil 1: Membuat Kalkulator Sederhana atau To-Do List yang datanya hilang kalau di-refresh.


🟡 Fase 3: Intermediate & ES6+ (Hari 41-60)
Masuk ke fitur modern JavaScript yang membuat koding lebih efisien.

Hari 41-45: Array Methods sakti: .map(), .filter(), .reduce(), dan .find().

Hari 46-50: Arrow Functions dan Template Literals.

Hari 51-55: Destructuring, Spread, dan Rest Operator.

Hari 56-60: Mengenal LocalStorage agar data To-Do List kamu tidak hilang meski browser ditutup.


🟠 Fase 4: Asynchronous & API (Hari 61-80)
Ini adalah "jantung" dari aplikasi modern. Penting untuk proyek seperti AnimeLib.

Hari 61-65: Memahami JSON (seperti yang kita bahas di data Cloudflare tadi).

Hari 66-70: Callback, Promises, dan mimpi buruk para pemula: Async/Await.

Hari 71-75: Menggunakan fetch() untuk mengambil data dari API publik (Misal: Jikan API untuk data Anime).

Hari 76-80: Proyek Kecil 2: Membuat Aplikasi Cuaca atau Katalog Anime sederhana menggunakan API.

🔴 Fase 5: OOP, Tooling, & Persiapan Framework (Hari 81-100)
Mempersiapkan diri ke level profesional.

Hari 81-85: Dasar OOP (Object Oriented Programming) di JS: Class, Constructor, dan Inheritance.

Hari 86-90: ES Modules (import/export) dan pengenalan NPM/Vite.

Hari 91-95: Debugging tingkat lanjut di WebStorm dan Error Handling (try-catch).

Hari 96-100: Proyek Akhir: Membangun aplikasi Dashboard Transaksi ATK versi JavaScript murni yang interaktif.
